# Güvenlik bildirimi

Açıkları ve kullanıcı verilerini herkese açık issue içinde paylaşmayın. Depoda GitHub özel güvenlik bildirimi etkinse Security bölümünden bildirin. Etkin değilse depo sahibinden özel bildirim kanalı isteyin. Etkilenen sürümü, etkiyi ve yeniden üretim adımlarını belirtin. Örneklerden anahtarları çıkarın.
